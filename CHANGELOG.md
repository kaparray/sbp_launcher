## 1.0.0
First release of `sbp_launcher`, based on [smenateam/sbp](https://github.com/smenateam/sbp) 0.1.1.
Dynamic bank list and package-list-free bank detection.

**Breaking (compared to sbp 0.1.1):**
* Package renamed: `sbp` → `sbp_launcher`, import `package:sbp_launcher/sbp_launcher.dart`, asset paths `packages/sbp_launcher/assets/...`, method channel `sbp_launcher`
* Android: package `com.example.sbp` → `io.github.kaparray.sbp_launcher`, plugin class `SbpLauncherPlugin`, `minSdk 21`, Java/Kotlin 17
* iOS: pod `sbp_launcher`, plugin class `SbpLauncherPlugin`
* Android: the plugin manifest no longer declares `<queries>` for 20 bank packages; it declares `VIEW` intent queries for `*://qr.nspk.ru` and `https://qr.nspk.ru`
* iOS 12.0+, Dart 3.3+, Flutter 3.19+

**Features:**
* `Sbp.getBanks` → `SbpBanks(installed, others)`; detection settings `android: SbpAndroidDetection` and `ios: SbpIosDetection` (can be `disabled` per platform; the iOS default `queriesSchemesMax50` makes the 50-bank limit visible in IDE hints)
* iOS: debug-only warning when `LSApplicationQueriesSchemes` exceeds 50 entries or banks cannot be detected
* `sbpIosPriorityBankSchemes` — recommended 50 iOS schemes, `dart run sbp_launcher:ios_queries_schemes` prints or writes (`--write`) the plist block, `--add` / `--remove` / `--only` to edit the list
* `sbpExtraAndroidPackageNames` — several Android packages per bank, includes the new RSHB app `ru.rshb.ownfinance`
* `C2bmembersRepository` / `Sbp.loadBanks`: load `c2bmembers.json` from the NSPK portal with timeout, on-device cache (24 h TTL), stale-cache and bundled-snapshot fallback
* `Sbp.launchBank` → `SbpOpenResult` (`opened` / `notInstalled` / `error`), never throws
* Android: banks are detected by the ability to open `<schema>://qr.nspk.ru/` (`queryIntentActivities`), including banks missing from any static list; `C2bmemberModel.installedPackageName` holds the real package
* Bundled snapshot updated to 195 banks (generated by `tool/update_c2bmembers.dart`), new optional fields `webClientUrl`, `isWebClientActive`

**Fixes:**
* iOS: `openBankIOS` returns the real result of `UIApplication.open` instead of always `true`
* iOS: no force unwraps — bad arguments return `INVALID_ARGUMENT` instead of crashing
* Android: PackageManager queries and icon encoding moved off the main thread
* Android: `openBank` retries without `setPackage` and returns `NOT_INSTALLED` instead of a raw exception
* Corrupted package names in the bundled list (`ru.avangard.packages/sbpent`, `com.intervale.packages/sbpas`)
* JSON parsing tolerates missing, extra and mistyped fields

* Android 12+: bank apps that only handle `https://qr.nspk.ru` are found (`MATCH_ALL`) and opened with the original link
* iOS 17+: URLs without a scheme are rejected instead of reported as `notInstalled`

**Deprecated:** `Sbp.openBank` (use `Sbp.launchBank`), `C2bmemberModelAndroidLocalData`
